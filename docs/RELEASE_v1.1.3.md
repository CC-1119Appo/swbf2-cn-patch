# 星球大战：前线 II 简体中文补丁 v1.1.3

字幕**全部烧录进影片**（过场 35 段 + 开场 2 部），GOG 与 Steam 表现一致，不依赖运行时钩子。

## 本次包含

- 界面汉化 5000+ 条（菜单 / HUD / 任务 / 武器单位名）
- 中文字体：IBM Plex Sans SC，覆盖原版 5 档 + Remaster 三套
- 过场与开场动画中文字幕（内嵌）
- 部署界面「单位数量」重叠修复
- 专有名词对齐官方译名库
- 单文件安装器，兼容 Windows XP SP3+

## 下载哪个

| 文件 | 适用 |
|---|---|
| **SWBF2_汉化安装器_v1.1.3.exe** | 全部（推荐） |
| SWBF2_汉化_Remaster_封装动画_v1.1.3.zip | 已装 Remaster 1.5r2 |

## 安装

运行安装器 → 选 `...\Star Wars - Battlefront 2\GameData` → 选版本 → 安装 → 用 `SWBF2_CN.exe` 启动。

## 修复记录

- **Steam 无字幕**：Steam 版 exe 启用 ASLR 且函数布局不同，旧版运行时字幕钩子无法定位；v1.1.3 改为内嵌字幕，彻底绕开
- **Steam 缺失文本**：补齐 `ifs.trailer.title` 等 Steam 独有键
- **原版载入页偏移**：恢复为与英文原版一致的位置
- **部署界面重叠**：安装器现在会一并安装修复后的 `ingame.lvl`

## 已知限制

- 社区 v1.3/v1.5 Extension 的自定义菜单项为脚本硬编码，无法汉化
- 部分载入页标题字号偏小
