# 星球大战：前线 II 简体中文补丁 v1.2.1

字幕全部烧录进影片（过场 35 段 + 开场 2 部），GOG / Steam 表现一致，不依赖运行时钩子。

## 本次更新

- **新增 Windows XP 支持**：安装器提供 XP 专用启动器 `SWBF2_CN_XP.exe` + `cn_hook_xp.dll`（无 CRT 依赖，子系统 5.01）
- **安装器可检测系统版本**：显示「Windows 11 (10.0.26300)」这类真实版本（`RtlGetVersion`），并自动预选启动器
- **修复启动器单选不勾选**：控件 ID 重号（112）导致「Vista / XP」始终空白
- 安装页面新增「启动器」选择，可手动切换（做盘/离线部署时有用）
- v1.2.0 的全部内容：移除外挂字幕残留、Remaster 部署界面修复、汉化状态检测、一键还原

## 使用

1. 运行 `SWBF2_汉化安装器_v1.2.1.exe`
2. 选择游戏目录 → 点「检测版本」（会显示系统、平台、Remaster、汉化状态）
3. 确认「安装版本」与「启动器」，点「开始安装」
4. 用 `SWBF2_CN.exe`（Vista+）或 `SWBF2_CN_XP.exe`（XP）启动

## 还原

- 「还原原版」：用内置原始 core/ingame/shell 覆盖回去
- 「还原备份」：还原安装时备份到 `_cn_backup` 的文件
- 影片用 Steam/GOG 的「验证文件」恢复

## 已知限制

- 社区 v1.3/v1.5 Extension 的自定义菜单项为脚本硬编码，无法汉化
- 部分载入页标题字号偏小
