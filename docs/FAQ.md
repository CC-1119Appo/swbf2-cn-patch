# 常见问题

**Q：进主菜单就闪退？**
A：多半是版本装错。装了 Remaster 却用原版包（或反之）会这样。请用安装器的「自动检测」，或确认 `GameData\addon\Remaster` 是否存在后再选。

**Q：装了 v1.3/v1.5 Extension 扩展 mod，暂停菜单还是英文？**
A：扩展把那些菜单项重写成了脚本里的硬编码字符串（8 位编码，放不下中文），无法通过翻译文件汉化。走 Locl 的条目（如「退出到 Windows」）已是中文。

**Q：过场动画没有字幕？**
A：外挂模式需窗口化/无边框（独占全屏下叠加层不可见）；或改用「封装动画」版。

**Q：开场动画字幕和画面不同步？**
A：字幕按影片时间轴显示；若整体偏移，可反馈具体是偏早还是偏晚。

**Q：部署界面「单位数量」压住按钮？**
A：安装器默认不带布局修复；手动包里有 `optional\ingame.lvl`，复制到 `data\_lvl_pc\` 即可（扩展 mod 玩家慎用）。

**Q：顶部状态栏文字被裁掉一半？**
A：已修复（原版字体小字档下移 3px）。若仍异常，请确认用的是 v1.1。

**Q：能用 Windows XP 吗？**
A：安装器本身兼容 XP SP3（无 CRT 依赖、子系统 5.01）；但 Remaster 1.5r2 模组可能需要更新的系统，XP 建议用「原版 1.1」。
